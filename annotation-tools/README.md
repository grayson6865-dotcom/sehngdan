## 打开与使用

- 本地入口：`http://127.0.0.1:8777/xppen-christmas-2026-annotated.html`
- 文件入口：项目根目录 `xppen-christmas-2026-annotated.html`。批注脚本、Markdown 和 Mermaid 库已内嵌。
- 右上角工具条：批注管理、流程图、关联系统；左侧手柄可拖动。
- 悬停或点击橙色编号打开需求浮窗，拖动标题栏移动，用 X 关闭。
- 管理面板中“查看”会切换批注专用 Demo 场景并打开目标业务弹窗；这会改变批注副本的演示进度。副本进度与业务原型使用不同存储键。
- 新增批注：选择页面模块，填写模块名称和 Markdown，预览后保存。删除有二次确认。
- 流程图：选择流程，编辑名称和 Mermaid，保存预览；支持新增、删除、缩放、全屏、折叠编辑区、上传或粘贴图片。
- 关联系统：默认六个外部承接页面，各有独立编号1；通过上传或粘贴补充截图，使用独立批注管理维护内容。更换截图保留该页批注坐标。
- 修改仅保存在当前浏览器 localStorage，**不会自动写回 HTML 或原始 PRD**。使用“导出 prd.md”保留最新的三类内容；换浏览器/换设备不会自动同步。
