# 邮件订阅奖励调整 Spec（待评审）

## 1. 目标与范围

在圣诞活动页面识别用户是否订阅邮件，对未订阅用户展示订阅入口。用户完成订阅后，可获得 1 点用于限时抽奖的常规能量。

本文是需求评审稿；除标注为“已确认”的内容外，建议与待确认事项均未作为已实现或最终业务规则。

## 2. 已确认的需求

1. **奖励类型**：订阅成功后奖励 1 点常规能量。按现有规则，1 点常规能量可在限时抽奖窗口内抽奖 1 次，不用于圣诞日抽奖。
2. **已订阅用户**：不展示订阅入口，不补发奖励。
3. **订阅方式**：在活动页面内完成订阅操作。
4. **入口样式与位置**：采用紧凑横条，放在画室进度区下方、小镇拼图区域上方；包括订阅说明和“订阅邮件”按钮。
5. **入口文案方向**：展示“订阅邮件，获得 1 点能量”，并说明能量可用于限时抽奖。精确文案与多语言版本实施时核对。
6. **订阅邮箱**：默认填充当前登录账号的邮箱，用户可修改并输入其他邮箱。账号没有邮箱时的处理待确认。
7. **奖励次数**：同一账号在本次活动中最多获得一次订阅奖励；退订后重新订阅不重复发放。
8. **订阅成功时点**：收到已有邮件订阅系统的成功结果后，视为订阅成功；本次原型模拟该成功结果。
9. **奖励时段和进度**：活动期间符合资格的用户，点亮 18 块后仍可领取；能量仅可在限时抽奖有效窗口内使用。
10. **本次范围**：仅制作原型演示；真实订阅状态由后续接口判断，本次不接入现有订阅系统或真实发奖。

## 3. 页面状态（建议，待确认）

| 状态 | 建议展示 / 处理 |
| --- | --- |
| 未登录 | 是否展示入口及点击后的登录衔接待确认。 |
| 登录后查询中 | 不将未知状态当作未订阅；展示加载状态或暂不展示入口。 |
| 未订阅 | 展示紧凑入口；点击后在活动页面内进行订阅，默认填充当前账号邮箱并允许修改。 |
| 订阅已确认且奖励发放成功 | 提示订阅成功及获得 1 点常规能量，刷新能量余额，入口不再展示。 |
| 已订阅 | 不展示入口，不补发奖励。 |
| 状态查询失败 | 不误判为未订阅；提示或重试方式待确认。 |
| 订阅失败或结果未确认 | 不提示奖励已到账；告知用户结果并允许后续重试。 |
| 订阅成功但奖励发放结果未确认 | 避免显示发放成功；记录待处理状态，支持查询或重试，避免重复发放。 |

## 4. 奖励与记录（建议，待确认）

- **已确认**：按活动和用户账号限制奖励次数，每个账号本次活动最多获得一次；退订后重新订阅不重复发放。重复点击、接口重试或重复通知也不能重复加能量。
- 建议在服务端确认订阅结果和奖励资格后记账，保留发放时间、来源、状态及关联记录，供排查。
- **已确认**：成功获得的 1 点加入常规能量余额；活动期间达到 18 块后仍可领取，使用时遵循限时抽奖窗口规则。活动开始前、结束后的处理待确认。
- 已确认退订后重新订阅不重复发放；退订是否扣回已获能量、换邮箱或更换账号时如何识别资格，待确认。
- 限时抽奖仍按既有 6 / 12 / 18 块门槛及有效窗口开放；订阅本身是否可直接触发抽奖窗口，待确认。

## 5. 涉及范围

- **活动页面**：未订阅入口、页面内订阅操作、加载/成功/失败提示、能量余额刷新、中英文和移动端布局。
- **订阅状态来源**：已有邮件订阅系统；系统名称、查询及订阅接口、账号与邮箱的关联方式待确认。收到系统成功结果视为订阅成功。
- **奖励服务**：查询资格、发放常规能量、记录结果与防止重复发放；具体接口和责任系统待确认。
- **静态原型**：使用模拟状态和模拟订阅结果演示入口、填写邮箱、成功/失败及能量变化；不能作为真实订阅或发奖已完成的证明。

## 6. 待确认问题

1. **正式接口待确认**：真实订阅状态由后续接口判断；当前仅做原型演示。账号邮箱与其他邮箱的关联、查询口径以及其他邮箱已订阅时的处理留待接口对接时确认。
2. **邮箱为空或无效**：账号没有邮箱时如何展示？输入空值或格式错误时如何提示？
3. **活动边界**：活动开始前、结束后的入口及奖励处理待确认；活动期间 18 块后仍可领取已确认。
4. **未登录用户**：是否先展示入口，点击后要求登录并继续订阅？
5. **入口收起时点**：订阅成功但奖励仍在处理中时，入口和处理结果如何展示？
6. **退订后已发奖励**：是否保留已经获得的能量？更换邮箱或账号时如何识别资格？
7. **现有订阅系统**：系统名称、查询和订阅接口、成功结果定义及账号关联方式是什么？
8. **提示内容**：订阅具体邮件类别、用户授权说明和隐私说明由谁提供？

## 7. 建议验收场景

- 未订阅用户看到入口；已订阅用户不看到入口且不补发。
- 订阅成功后常规能量增加 1 点，圣诞能量不变；限时窗口关闭时不能直接开始抽奖。
- 页面刷新、重复点击、网络重试及重复结果通知不会重复发放。
- 订阅失败、状态查询失败、结果未知及发奖失败时不误报成功；恢复后的结果可核对。
- 18 块前后，活动期间符合资格的用户均可获得奖励；未登录、退订处理及活动起止边界按确认后的规则验证。
- 中英文、桌面与移动端入口清晰，成功后入口和能量显示同步。
