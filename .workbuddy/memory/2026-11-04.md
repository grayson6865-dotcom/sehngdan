## 复制失败兜底（好逑反馈连弹「复制失败」）

- 原因：`navigator.clipboard.writeText` 在 file://、iframe 预览、无剪贴板权限时会 reject，原代码只 toast 提示「请手动选择券码」，而券码在 button 里无法选中。
- 现在 `copyText()` 三级兜底：clipboard API → `execCommand('copy')`（隐藏 textarea）→ 弹「你的折扣码」弹窗，input 只读且自动全选。
- `toast()` 增加同文案去重：`data-msg` 相同则重置计时，不再堆叠（连点 4 次只保留 1 条）。
- 版本 `20261104q`，commit `52bce9f`。

## 项目约定（踩坑记录）

- 构建脚本里 `re.sub` 的替换串含 JS 代码（`\w` 等），必须用 lambda 形式，否则报 `bad escape \w`。
- 单文件版构建清单是 8 个 JS：i18n / data / art / draw / reel / keepsake / activity-rules / app（README 里只写了 7 个，漏了 activity-rules）。
- 无头 Chrome 验证方式：注入脚本 + `--virtual-time-budget` + `--dump-dom`，比截图更适合断言文案；语言必须写在 `<head>` 里设置 `localStorage.xppen-xmas-lang`，放 body 末尾无效（i18n 已先执行 detect）。
- 本机 headless Chrome 在受沙箱约束的 shell 里会报 `sandbox initialization failed`，必须加 `--no-sandbox`，否则 dump 输出 0 字节。
- 本机后台 `python3 -m http.server 8777` 会被回收，用前先 `lsof -iTCP:8777` 确认。
